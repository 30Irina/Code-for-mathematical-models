# Mathematical models and finite-difference schemes for interaction of the counter-propagating optical pulses in a medium with non-local non-linear response

## Launch instructions:

* Launch instructions:
For each of the three mathematical models, program code is provided. When running, you will need to enter some parameters: for the first model - D_x, alpha_0, L_s (corresponds to L_l in the article), L_z, delta_0, hi, z_c, L_t, N_t (number of time points), N_x (number of points along x), N_z (number of points along z); for the second and third models - D_x, alpha_0, L_s, L_z, delta_0, L_t, N_t, N_x, N_z. Other parameters can be changed directly in the program code.
* |A|^2 for the first model is written to tabl_A.csv
* |A_plus|^2+|A_minus|^2 for the second and third models is written to tabl_A.csv
